# DBGate Setup
1. Install DBGate.
2. Add a PostgreSQL connection.
3. Host: localhost (or your database host).
4. Port: 5432.
5. Database: poct_management.
6. User: poct_user.
7. Password: value from `.env`.
8. Test and save the connection.

Use DBGate to inspect Django-created tables, constraints, indexes, foreign keys, and to run administrative/report queries. The Django application itself should use the Django ORM for ordinary CRUD operations.
