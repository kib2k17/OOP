# Nonfunctional Requirements
- Security: authenticated access, CSRF protection, hashed passwords, environment-based secrets.
- Maintainability: modular Django apps, documented models, reusable templates.
- Reliability: validation and relational constraints.
- Usability: responsive Bootstrap interface and consistent navigation.
- Performance: paginated/filterable lists for production-scale use.
- Portability: runs on Windows/macOS/Linux with Python and PostgreSQL.
- Testability: unit and integration tests for business rules and views.
- Privacy: synthetic data only for capstone demonstration.
