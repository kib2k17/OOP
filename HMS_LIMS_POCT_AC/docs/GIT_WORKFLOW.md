# Git / GitHub Workflow


Recommended branches: `main`, `develop`, `feature/authentication`, `feature/operators`, `feature/devices`, `feature/competency`, `feature/qc`, `feature/maintenance`, `feature/inventory`, `feature/reports`.

Typical commands:
```bash
git init
git add .
git commit -m "Initialize Django POCT management project"
git branch -M main
git remote add origin <your-github-repository-url>
git push -u origin main
```

Use small descriptive commits, pull requests for major features, and GitHub Issues for defects/tasks.
